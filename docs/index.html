pz-rust

Project Zomboid, rebuilt from scratch in Rust. Fast, cross-platform, and checked against the original with differential tests.

View on GitHub

What works today

Real map data. All 4,065 Muldraugh cells (4.16M chunks) decode byte-exactly from your own install.
wgpu renderer. Vulkan, DX12 and Metal. Every atlas page lives in array-texture slabs: one draw call per frame instead of 1,270.
Floors & roofs. Multi-storey buildings render with correct stacking; roofs hide when you walk indoors.
Deterministic sim. Fixed 30 Hz tick with wall-aware movement driven by the game's own tile properties.

Try it

git clone https://github.com/LakoMoor/pz-rust
cd pz-rust
set PZ_DIR=C:\path\to\ProjectZomboid
cargo run --release -p pz-viewer

WASD to walk, Shift to run, mouse wheel to zoom. --shot out.png renders a frame headlessly.

Roadmap

Characters & animation, doors, stairs, items and Lua scripting, zombies, audio, then a headless server with networking.

pz-rust is an unofficial fan project, not affiliated with or endorsed by The Indie Stone. It ships no game assets and requires your own legitimate copy of Project Zomboid. Screenshots show content from the original game. Inspired by horizon-rust/horizon.
